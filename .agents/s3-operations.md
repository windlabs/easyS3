# S3 操作规格（列表 / 上传 / 下载 / 删除）

## 通用约束

- 所有操作经 Rust 侧 `aws-sdk-s3` 执行（架构边界见根 `AGENTS.md`）。
- 所有耗时操作（上传 / 下载 / 批量删除）可取消。
- **自动重试（2026-10）**：上传 / 下载的**瞬时错误**（连接失败、超时、5xx / SlowDown 等未分类服务端临时错误）自动指数退避重试（300ms 起翻倍），次数可配（默认 3，0 = 关闭）；认证、权限、不存在、用户取消**不**自动重试。累计重试次数在任务中心可见。删除任务不自动重试（避免重复请求已成功对象），保持手动精确重试。
- 任务中心提供手动"重试"（精确命中语义见下），与自动重试叠加时仅重试最终失败的文件，不重复执行已成功对象。
- **请求超时（两类客户端，硬性约束）**：
  - 传输客户端（上传 / 下载对象体）：**不设操作超时**——大文件在慢链路上合法地耗时很长；停滞流保护兜底（流 20 秒无任何数据即中断报错，死链不挂死任务）。
  - 控制面客户端（列表 / Head / 计数 / 预览 / DeleteObjects / 测试连接）：单次尝试 30s 超时——服务端接受连接后不响应时，界面与任务不得无限等待。
- **手动"重试"精确命中失败项（以原参数重新开始）**：
  - 失败文件：直接重试。
  - 失败项为目录前缀（展开阶段"列出对象失败"）：重新展开该目录后再重试。
  - 目录下部分对象失败：仅重试其中失败对象，已成功对象不重复执行（下载避免 rename 冲突产生副本；删除虽幂等也不重复请求）。
- **对象 Key 规则**：原样支持中文、空格及 Unicode 字符，本地文件名与 key 互转不做额外转义（HTTP 层编码由 SDK 处理）；验收用例必须包含中文与带空格的文件名。
- 错误必须分类并以中文可读消息展示，不得包含 `secret_key`：

| 类别 | 触发 | 用户提示示例 |
|---|---|---|
| 连接失败 | endpoint 不可达 / 超时 / DNS 失败 | "无法连接到 \<endpoint\>，请检查地址与网络" |
| 认证失败 | 403 InvalidAccessKeyId / SignatureDoesNotMatch | "认证失败，请检查 Access Key / Secret Key" |
| 权限不足 | 403 AccessDenied | "没有权限执行该操作" |
| 不存在 | 404 NoSuchKey / NoSuchBucket | "对象或桶不存在" |
| 未知 | 其余 | 原始错误码 + 简述 |

## 1. 列表查询

- 进入连接先 `ListBuckets` 展示桶列表；进桶后 `ListObjectsV2`（`delimiter = '/'`）。配置了 `default_bucket` 的连接跳过桶列表，直接进入该桶。
- `CommonPrefixes` 渲染为虚拟文件夹，实现目录树浏览。
- key 以 `/` 结尾的 0 字节占位对象按"文件夹"渲染：不进入对象列表、不可下载；删除前缀时随前缀一并删除。
- **分页**：每页 1000（S3 上限），滚动到底自动用 continuation token 加载下一页；**禁止一次性拉全量**（桶可能巨大）。
- 过滤框为**前缀语义**：直接以 `prefix` 参数请求服务端过滤，不是当前页的子串搜索；UI 文案须体现"前缀"。
- 列：名称、大小、最后修改时间；默认按名称升序、文件夹在前，可点列头切换排序。

## 2. 上传

- 支持选择单文件、多文件、整个文件夹；文件夹上传保留相对目录结构（key = 当前前缀 + 相对路径）。
- 支持从系统文件管理器拖拽文件 / 文件夹到窗口上传（与手动选择走同一套确认与覆盖规则）。
- 开始前弹一次确认：显示"将上传 N 个文件到 \<前缀\>，**同名对象将被覆盖**"。不做逐文件同名检测。
- 传输实现（硬性约束）：
  - `aws-sdk-s3`（Rust）的 `put_object` **不会自动分片**，大文件必须手动实现 multipart：`create_multipart_upload` → `upload_part` → `complete_multipart_upload`。
  - 分片大小 ≥ 5MB（S3 最小分片限制，最后一个分片除外），建议 8–16MB；单文件最多 10000 片。
  - 流式读取本地文件，**禁止整文件读入内存**。
  - 取消或失败必须 `abort_multipart_upload`，否则残片永久占用存储。
- 并发：同一任务内文件间并发默认 2（常量可调）；进度事件分任务级 / 文件级两级 `emit` 到前端。
- 上传确认可选存储类别；默认 STANDARD。传输设置仅影响新任务。

## 3. 下载

- 单对象下载：保存对话框选目录，文件名取对象名。
- 同名冲突：覆盖 / 自动重命名 `name (1).ext` / 跳过 三选一；批量任务只弹**一次**，选择对整个任务生效。
- 下载"文件夹"（前缀）：不带 delimiter 递归列出全部对象（覆盖任意子层级），再逐个下载并保留目录结构；key 以 `/` 结尾的占位对象不下载。
- 流式写盘 + 进度事件；下载先写入同目录 `.part` 临时文件，异常退出后通过 HTTP Range 继续写入；服务端忽略 Range 时从头下载，完成后才替换最终文件。用户取消/放弃时删除 `.part`。
- **下载后打开（P0-10）**：对象行"打开"将对象下载到系统临时目录 `easys3-open`（文件名取 key 末段，剥离路径分隔符防目录穿越），下载完成后用系统默认程序打开；下载作为任务进入任务中心（进度反馈、可取消、可重试），不阻塞界面。
  - 临时目录在应用退出时清理（`RunEvent::Exit`）；崩溃残留由下一次打开前覆盖同名文件，不会无限累积。

## 4. 删除

- 删除不可恢复（无版本控制），**任何删除必须二次确认**；确认框显示目标数量与前缀（>10 个仅显示数量）。
- 多选批量删除用 `DeleteObjects`（单请求上限 1000 个对象，超出自动分批）。
- 删除"文件夹"（前缀）：不带 delimiter 递归列出全部对象（覆盖任意子层级，含以 `/` 结尾的目录占位对象）统计数量，确认后逐批删除；占位对象随前缀一并删除（与 §1 一致）。
- 部分失败时逐对象报告失败原因，已成功的不回滚。
- 批量请求整体失败（网络 / 服务错误）时：已完成批次的进度保留展示；该批及其后未执行的对象**逐个**记入失败（错误信息标注结果未知），保证「重试失败项」能精确命中这些 key（S3 删除幂等，重复删除安全）。

## 5. 对象预览

- **类型与上限清单**：
  - 图片（jpeg / png / gif / webp / bmp）≤ 20MB；
  - **PDF / 常见音视频（mp4 / webm / mp3，另支持 wav / ogg / flac / m4a）**：大小上限可配（设置页"预览大小上限"，默认 20MB，范围 1–100MB）；
  - UTF-8 文本（含 JSON / 常见代码文件）≤ 1MB；
  - **SVG 一律不预览**（webview 渲染 SVG 有 XSS 风险）；超出上限或检测为二进制（UTF-8 解码失败 / 含非法字符）时提示"请下载后查看"。
- 文本按**纯文本高亮**渲染（字符串 / 注释 / 数字 / 关键词着色），Markdown 渲染为只读结构化视图（标题 / 列表 / 引用 / 代码块）；一切预览内容均为文本节点渲染，**禁止按 HTML / 富文本渲染**（防 XSS 注入，`v-html` 禁用）。
- PDF / 音视频以 data URL 交前端内嵌展示，**不经临时文件中转**；如未来引入临时文件中转，关闭预览后必须立即删除。
- 内容经 Rust 单次 `GetObject` 读取，先 `HeadObject` 拒绝超限请求；小文件整块读入内存是"禁止整文件读入内存"约束的显式例外，仅限预览。

## 6. 桶内对象管理（P0）

- 新建文件夹写入当前前缀下的 0 字节 `名称/` 占位对象；名称非空、不含 `/`，同级重名需提示。
- **桶内复制 / 移动 / 重命名（同一连接内，跨连接仍为红线）**：
  - 一律使用服务端 `copy_object`，**不做整对象下载中转**；移动 / 重命名在复制成功后删除源对象（先复制后删，删除失败仅计入失败，不回滚）。
  - 单对象重命名：`目标前缀 + 新名称`；多选移动 / 复制：目标前缀由对话框指定（缺省当前前缀），目标 key = 目标前缀 + 原名 / 相对路径。
  - 文件夹（前缀）操作递归覆盖所有层级，0 字节目录占位对象一并处理；目录重命名 = 修改目标前缀末段。
  - **冲突策略**：目标存在同名对象时按统一冲突策略（覆盖 / 跳过）；"取消"由对话框取消按钮承担。
  - **大对象（> 5GB）**：复制前 `HeadObject` 前置检查，明确提示"超过 5GB，暂不支持服务端分片复制，请下载后重新上传"（不静默失败；该错误不参与自动重试）。
  - **任务化**：复制 / 移动 / 重命名均作为 Copy 类型任务进入任务中心，可取消；失败项支持"精确命中重试"（重试槽保存原始列表项 + 目标前缀 + 冲突策略，重新展开后仅执行失败范围）；瞬时错误参与自动重试（同上传 / 下载）。
  - 中文 / 空格 / Unicode key 全程原样支持（CopySource 的 bucket/key 需 URL 编码、`/` 保留，有单元测试）。
- 对象详情用 `HeadObject` 获取，不下载对象体；展示大小、修改时间、ETag、存储类别、Content-Type 和 `x-amz-meta-*`。

## 7. 服务端碎片管理（P0）

- 使用 `ListMultipartUploads` 分页列出当前桶未完成上传（key、发起时间、StorageClass），单个上传可用 `ListParts` 查看分片明细（编号、大小、时间、ETag）。
- 可勾选单个 / 批量 `AbortMultipartUpload` 清理；清理为高危操作，必须二次确认。
- 批量清理**逐项报告**：成功项从列表移除，失败项保留原信息并可再次勾选重试。
- 权限不足、服务端不支持时按通用错误规范提示。它不改变上传失败/取消时自动 abort 的既有规则。

## 8. 断点续传与传输队列持久化（P1-01）

- 上传和下载任务在入队时记录于应用配置目录 `transfers.json`，以连接 id、桶、对象/本地路径及必要传输选项关联；原子写入，且绝不记录凭据、Client 或签名 URL。重启后显示为可恢复任务，需用户显式逐项或全部恢复。
- multipart 上传创建后保存 `UploadId`、分片大小和已完成分片 ETag；恢复时 `ListParts` 校正进度，只传缺失分片。小文件不具备安全分片恢复条件，按原文件重新上传。
- 下载从同目录 `.part` 文件大小起请求 Range；不支持 Range 的服务端从头重新下载，避免拼接出损坏文件。最终文件仅在完整下载后写入。
- 恢复时使用原连接；原连接/密钥、本地源文件或下载目录不可用时返回明确中文错误并保留记录。取消或放弃任务清理恢复记录；取消/放弃的 multipart 必须 Abort，下载删除 `.part`；异常退出保留现场。

## 9. 预签名 URL（P1-02）

- 使用 Rust 侧 S3 Client 生成 GET（下载）和 PUT（上传）预签名 URL；前端不得接触凭据或自行签名。
- 有效期接受 1 秒至 7 天；批量下载链接使用统一有效期。生成结果可复制，批量结果可导出 UTF-8 文本清单。
- 预签名 URL 属于敏感临时凭证：日志、错误、任务状态与持久化配置中均禁止记录完整 URL。

## 10. 对象版本查看与恢复（P1-03）

- 版本列表使用 `ListObjectVersions` 按对象 key 过滤并处理分页，展示普通版本与删除标记。桶未开启版本控制、接口不支持或权限不足时提供可理解的中文提示。
- 恢复历史版本使用带 `versionId` 的 `CopyObject` 原地复制为当前 key；删除标记不提供恢复按钮，普通历史版本恢复前必须确认。
- 仅覆盖单对象版本查看与恢复；不得扩展为全桶历史时间线或批量 Time Travel。

## 11. 对象标签与 ACL 只读（P1-04）

- 使用 `GetObjectTagging` / `PutObjectTagging` 读取、替换对象标签；标签 key 非空，空标签集允许保存。
- 使用 `GetObjectAcl` 只读展示所有者及授权，不提供 PUT ACL 等权限修改能力。
- 标签和 ACL 的读取必须相互独立；某一接口权限不足时，仅展示该接口的分类错误，另一项继续可用。

## 12. 桶管理与版本控制（P1-05）

- 仅非限定单桶连接可调用 `CreateBucket` / `DeleteBucket` / `GetBucketVersioning` / `PutBucketVersioning`；限定单桶连接前后端均不提供或拒绝这些操作。
- 删除桶必须在 UI 二次确认；仅服务端允许的空桶删除成功，非空/权限不足等失败按通用错误规范展示。

## 13. 同连接跨桶复制与移动（P1-06）

- Copy 任务明确区分源桶与目标桶，但两者必须属于当前同一连接；源对象 Head、CopySource、源删除分别作用于正确的源/目标桶。
- 跨 region 不做下载中转；直接请求服务端 CopyObject，失败时保留任务失败项供重试并展示服务端分类错误。
- 移动保持先复制、后删除源对象的顺序；目标冲突策略与 P0 桶内复制一致。

## 14. 单向同步（P1-07）

- 同步范围仅为当前桶前缀与用户选择的一个本地目录；本地→S3 和 S3→本地均为单向操作，禁止自动合并双端变更或实时监听。
- 计划阶段递归列出远端对象（不含目录占位对象）与本地文件，按相对路径及大小比较；输出新增、更新、跳过及可选删除项。删除传播默认关闭，开启后必须二次确认。
- 执行阶段只传输计划的新增和更新项，不重传跳过项；远端删除复用 Delete 任务，本地删除作为 Delete 任务，传输和删除均可取消，失败项保留任务中心精确重试入口。

## 15. 全局搜索与高级过滤（P1-08）

- DSL 支持 `size>` / `size<`（B、KB、MB、GB）、`modified>Nd` 与 `class=`，多个条件用 `AND` 连接；无效语法在发起请求前拒绝并返回中文帮助。
- 搜索按 S3 `ListObjectsV2` 分页扫描，不影响对象浏览页的 continuation token。当前桶或跨桶范围均作为后台 Search 任务执行，取消标志在每页和每桶间检查；跨桶扫描并发上限固定为 1。
- 搜索结果仅返回元数据并允许前端导航到目标桶/目录，不下载对象体。

## 16. 批量下载 ZIP（P1-10）

- 文件夹选择先递归展开（排除以 `/` 结尾的目录占位对象），ZIP 条目使用相对前缀路径；多选单文件使用完整 Key，避免同名条目冲突。
- 对象内容逐个下载到系统临时工作文件，再分块写入目标 ZIP，写入后立即删除工作文件；不得把完整对象或整个 ZIP 置入内存。
- ZIP 下载进入任务中心、可取消并报告失败对象；取消时清理未完成 ZIP 与临时工作目录。

## 17. 仅上传新增 / 变更与空文件夹（P1-11）

- 上传确认可选择“仅上传新增 / 变更文件”。启用时递归比较远端同 key 的大小：大小相同跳过，缺失或大小不同进入上传计划；确认框及任务中心显示上传、跳过和空目录数量。
- 本地空目录写入以 `/` 结尾的零字节占位对象；普通上传不改变既有覆盖语义。

## 18. 完整性校验（P1-12）

- 下载完成后，对单部件对象的 32 位 ETag 计算本地 MD5 并比对；不一致时任务失败且保留已下载文件以便排查。multipart 复合 ETag（含 `-`）不代表整体 MD5，明确跳过校验。
- 上传后的回读校验目前仅支持单部件 ETag；分片复合 ETag 跳过并在界面说明。

## 19. Content-Type 与自定义元数据编辑（P1-20）

- 对象详情可编辑 Content-Type 与 `x-amz-meta-*` 自定义键值；保存用 CopyObject 原地复制并设置 `metadata_directive=REPLACE`。
- CopyObject 单请求超过 5GB 时必须明确拒绝；失败按通用分类提示。编辑不修改对象体。

## 20. 归档对象恢复（P2-03）

- GLACIER / DEEP_ARCHIVE 对象详情显示恢复入口和服务端 restore 状态；可选择 1–365 天保留期及 Expedited / Standard / Bulk 检索速度。
- 非归档对象不显示恢复入口。恢复请求失败按通用错误规范显示，恢复完成后可沿用下载/预览流程。

## 21. 桶 / 前缀用量统计（P2-10）

- 用控制面客户端分页扫描对象，计入目录占位对象，累计对象数与总字节。扫描作为 Stats 后台任务执行，按页检查取消并在任务中心显示进度。
- 统计完成后可在对话框查看并导出 JSON；扫描失败按中文分类错误展示，不阻塞对象浏览。

## 22. 文本在线编辑（P2-09）

- UTF-8 文本预览可切换为纯文本编辑，内容上限 1MB；不渲染 HTML 或富文本。保存前强确认覆盖远端对象，保存失败保留编辑缓冲供重试。
- 保存以 `PutObject` 覆盖当前 key，成功后刷新列表和预览；编辑会话不写本地临时副本。

## 23. 本机操作历史（P2-08 一期）

- 任务终态记录本机时间、连接名、桶、操作类型、状态与失败摘要，持久化于应用配置目录 `history.json`；不得记录 Secret Key 或完整签名 URL。
- 历史可按当前连接和时间范围查看、导出 JSON。历史只记录结果，不能恢复或重放任务；回收站/软删除作为二期独立能力。

## 24. IaC 与 SDK 代码导出（P2-07）

- 当前桶可导出不含凭据的 Terraform、CloudFormation 或 CDK 桶骨架；对象操作可生成 TypeScript / Python SDK 获取对象片段。所有导出均不包含 Access Key、Secret Key 或签名 URL。

## 25. 回收站软删除（P2-08 二期）

- 连接可选配置回收站前缀。删除确认可选择软删除：先服务端复制到 `回收站前缀/时间戳/`，再删除源对象；未配置回收站或未勾选时保持硬删除语义。
- 正常列表默认隐藏回收站前缀。回收站窗口支持浏览、选中恢复到指定目标前缀（复制回目标并删除回收站副本）及永久清空；所有操作沿用任务中心进度、取消与失败反馈。

## 26. 剪贴板粘贴上传（P2-11）

- 对象浏览状态下粘贴剪贴板图片时，Rust 侧转为带时间戳的 PNG 临时文件并复用上传确认流程；WebView 暴露剪贴板文件本地 path 时，直接复用文件上传确认流程。
- 无法识别的剪贴板内容或当前不在对象浏览/只读模式时静默忽略，不输出错误。
