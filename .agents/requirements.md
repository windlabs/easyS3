# 功能范围与核心流程

## 用户与场景

- **目标用户**：内部开发 / 运维 / 测试人员，非 S3 专家。UI 一律使用"连接、桶、文件夹、文件"等业务词汇，不暴露 prefix、multipart 等协议术语。
- **典型场景**：① 拉取构建产物 / 日志到本地；② 上传部署包 / 备份文件；③ 清理过期对象。
- **优先级内涵**：浏览 + 下载是主干，上传其次，删除是低频高危操作（确认要重）。

## 功能清单（全部，不分期，一次性交付）

| # | 功能 | 说明 |
|---|------|------|
| 1 | 连接管理 | 新建 / 编辑 / 删除 S3 服务配置（"连接"），测试连接（结果随配置持久化展示），切换当前连接；支持限定单桶连接（`default_bucket`）；服务用自签证书时可指定 CA 证书文件 |
| 2 | 列表查询 | 浏览桶列表与对象列表（虚拟目录树、面包屑、分页、前缀过滤），可随时返回桶列表（限定单桶连接除外） |
| 3 | 上传 | 文件 / 文件夹上传，支持从系统拖拽 |
| 4 | 下载 | 对象 / 文件夹（前缀）下载到本地 |
| 5 | 删除 | 单个 / 多选批量 / 整前缀删除 |
| 6 | 对象预览 | 图片与文本对象直接预览（超限提示下载；SVG 不预览） |
| 7 | 复制 Key | 复制对象完整 Key，便于贴到代码 / CLI |

## 核心用户流程

1. **首次使用**：新建连接（名称、endpoint、AK/SK）→ 测试连接 → 保存 → 进入桶列表（或限定桶）。
2. **日常使用**：选连接 → 桶列表 → 进桶 → 按虚拟目录浏览 → 上传 / 下载 / 删除 / 预览 / 复制 Key。
3. **切换连接**：任意时刻可切换；进行中的上传 / 下载任务不中断、不取消。

## 界面与交互

- **布局**：左侧"连接 + 桶"选择区，右侧对象列表；顶部面包屑显示当前桶 / 目录路径，可点击逐级返回；进入桶后侧栏与面包屑提供"返回桶列表"入口（限定单桶连接不显示——无桶列表）。
- **多选反馈**：对象列表多选后，工具栏显示已选数量。
- **确认框关闭时机**：上传 / 删除等操作在确认框内点击确认、且任务成功入队后，确认框**立即关闭**（不等待任务执行完成，进度与结果由任务中心呈现）；仅当入队失败（如同步报错、无可上传文件）时保持打开并提示错误。
- **传输任务中心**：全局浮窗，展示进行中 / 已完成 / 失败任务；失败任务提供“重试”（精确命中失败项，展开失败的文件夹重新展开后重试，语义见 `.agents/s3-operations.md`），支持清除记录；进行中的上传 / 下载任务显示实时传输速度。
- **任务中心自动收起**：当全部任务均结束**且无任何失败项**时，浮窗在 5 秒后自动收起（清掉已完成记录）。以下情况不自动收起：仍有任务进行中、存在失败项（需保留“重试失败项”入口）、鼠标悬停于浮窗上（悬停时暂停计时，移出后重新计时）。计时期间有新任务开始则取消计时并重新展开浮窗。
- **错误提示**：错误 Toast 停留时间长于普通提示（默认 8 秒），便于阅读与排查。
- **退出保护**：仍有进行中的传输任务时关闭窗口，需二次确认（提示任务将中断且进度不保留）；确认后退出。
- **空状态**：无连接显示新建引导页；空桶 / 空目录显示占位提示。
- **拖拽上传**：从系统文件管理器拖文件 / 文件夹到窗口即上传到当前目录。

## 范围红线（明确不做，除非用户明确提出）

- ACL / 权限管理、STS / 临时凭证
- 跨连接复制 / 同步 / 移动（同一连接内跨桶复制 / 移动、单向本地同步已支持）
- 配置导入 / 导出
- 自动更新（Tauri updater）：手动下载新安装包覆盖安装

## P0 增补边界（2026-10）

- 支持同一连接内的桶内新建文件夹、重命名、复制和移动；跨连接复制/同步仍为范围红线。
- 对象详情可只读查看大小、修改时间、ETag、存储类别、Content-Type 与自定义元数据。
- 传输设置（持久化于应用配置目录 `settings.json`，损坏/缺失回落默认值）：
  - 瞬时错误自动重试次数（默认 3，0 = 关闭，上限 10）：仅作用于上传 / 下载的瞬时错误（连接失败、超时、5xx / SlowDown 等未分类服务端临时错误）；认证、权限、不存在、用户取消不自动重试；删除保持"手动精确重试"语义不变。重试按 300ms 起指数退避，累计次数在任务中心可见。
  - 全局上传 / 下载限速（KB/s，0 = 不限速）：跨任务共享令牌桶，速率调整对进行中任务**即时生效**。
   - 单任务文件间并发数（默认 2，1–8）、multipart 分片大小（默认 8MB，5–64MB，只影响新任务）、最大并发任务数（默认 3，超出排队，状态显示"排队中"，可取消）。
- **全局偏好入口**：界面顶部提供自绘“配置”菜单，统一维护主题、下载目录与传输设置；左侧栏仅承担连接管理与桶/对象导航，不能再混入全局偏好项。
  - 顶栏左侧展示应用品牌，右侧展示“配置”入口，避免仅一个菜单项造成空白菜单栏或与左侧品牌重复。
  - 主题（跟随系统 / 浅色 / 深色）在菜单内以单选项展示，选择后立即生效并持久化。
  - 菜单内可开关“记住下载目录”、设置/更换已记住的下载目录，并在存在目录记录时清除；没有目录记录时清除项不可用。关闭记忆开关但仍保留路径时，必须明确显示“已保存，未启用”。
  - “传输设置…”打开传输参数设置对话框；本次仅调整入口与布局，不改变既有持久化位置、默认值或传输行为。
  - 配置菜单支持点击外部关闭、Esc 关闭并将焦点还给入口；键盘打开后支持上/下方向键、Home、End 在可用菜单项之间移动焦点。
- Secret Key 优先写入 OS Keychain；无可用 Keychain 时使用本机 AES-GCM 加密配置。前端读取连接状态不得得到 Secret Key；编辑时留空表示保留既有密钥。
  - 写入 Keychain 后**必须用独立句柄读回校验**：keyring 未启用平台后端时会退化为不持久化的 mock（每次 Entry 独立、`set_password` 假成功），校验不通过一律落到 AES-GCM 加密文件兜底，避免据此清空明文导致密钥永久丢失。平台后端仅 Windows（`windows-native`）/ macOS（`apple-native`）启用；Linux 不启用后端、统一走加密文件兜底。
- 扩展安全预览（PDF、音视频、代码、Markdown），SVG 继续禁止预览；支持下载后用系统默认程序打开；下载位置默认记住上次目录。
- 桶内可列出并清理历史 multipart 残片，操作必须二次确认。

## P1-01 断点续传与传输队列持久化（2026-10）

- 未完成上传和下载任务持久化于应用配置目录的 `transfers.json`；文件原子写入且不含 Secret Key、Client 或签名 URL。重启后任务中心展示“可恢复”任务，支持逐项恢复、全部恢复或放弃，且不会自动发起网络传输。
- 恢复必须使用任务创建时的原连接；原连接/密钥已删除、本地上传源文件或原下载目录不存在时，保留记录并给出中文错误。
- 大文件上传保存 `UploadId`、分片大小与已完成分片；恢复时以服务端 `ListParts` 为准，只补传缺失分片。下载写入同目录 `.part`，恢复时通过 HTTP Range 从已有偏移继续；不支持 Range 时安全回退为从头下载，完成后才替换最终文件。
- 用户取消或放弃任务时清除恢复记录；上传取消/放弃必须 Abort multipart，下载取消/放弃删除 `.part`。异常退出不主动 Abort，以便下次恢复或在碎片管理中清理。

## P1-02 预签名 URL（2026-10）

- 桶内可为一个或多个文件生成临时下载链接，也可为指定对象名称生成上传链接；链接有效期支持 1 秒至 7 天，默认 1 小时。
- 下载链接支持一键复制与导出纯文本清单；完整签名 URL 不得写入应用日志、任务记录或错误信息。
- 生成失败沿用 S3 错误分类（权限不足、认证失败、连接失败等）；文件夹不可直接生成下载链接，应提示用户选择文件。

## P1-03 对象版本查看与恢复（2026-10）

- 单对象详情提供版本列表，显示版本 ID、大小、修改时间、当前版本与删除标记；列表分页读取，不能只显示首批结果。
- 可将非删除标记的历史版本恢复为当前对象，恢复前必须确认。仅支持单对象恢复，不提供全桶 Time Travel。
- 桶未开启版本控制、服务端不支持该接口或无权限时，显示“无法读取版本：桶可能未开启版本控制，或没有权限”的明确中文提示。

## P1-04 对象标签与 ACL 只读（2026-10）

- 对象详情可读取、增加、编辑和保存 S3 对象标签；空标签集也必须能进入编辑并新增标签。标签名称不能为空。
- ACL 仅展示所有者与授权条目，不提供任何 ACL 修改入口。标签与 ACL 请求独立处理，任一权限不足不得阻断另一项的可用操作。
- 标签或 ACL 权限不足时沿用 S3 中文分类提示。

## P1-05 桶管理与版本控制（2026-10）

- 非限定单桶连接可创建桶、删除空桶、查看与切换桶版本控制（Enabled / Suspended）。创建时按既有桶名规范校验；删除须二次确认，服务端报告桶非空时原样给出中文错误。
- 限定单桶连接不显示桶管理入口，后端同样拒绝桶创建、删除和版本控制命令。

## P1-06 同连接跨桶复制与移动（2026-10）

- 复制/移动对话框可选择当前连接内的目标桶与目标前缀；仍禁止跨连接复制、同步和移动。
- 使用服务端 `CopyObject`，移动在复制成功后删除源对象；目标冲突策略、取消、失败精确重试与既有桶内复制一致。
- 不做本地下载中转。跨 region 是否可用由服务端复制能力决定；服务端拒绝时按分类错误提示用户。

## P1-07 本地文件夹与前缀单向同步（2026-10）

- 支持本地文件夹 → 当前桶前缀及当前桶前缀 → 本地文件夹两种单向同步；仅比较大小，相同大小默认跳过，大小不同视为更新。
- 同步前必须展示新增、更新、删除、跳过数量与差异预览；删除传播默认关闭，开启后再次确认。删除传播方向为本地→S3 删除远端多余对象、S3→本地删除本地多余文件。
- 计划内新增/更新以后台上传或下载任务执行，删除传播以独立删除任务执行；均支持取消、进度、自动重试（传输）与失败项精确重试。不得实现双向同步或实时文件监听。

## P1-08 全局搜索与高级过滤（2026-10）

- 提供高级过滤 DSL：`size>10MB`、`size<1GB`、`modified>30d`、`class=GLACIER`，条件以大写 `AND` 连接；输入框提供内联语法帮助，错误必须给出中文说明。
- 搜索范围可选当前桶或当前连接的全部桶；结果显示桶名、完整 Key、大小，并可跳转到其所在目录。
- 搜索作为可取消后台任务进入任务中心；跨桶扫描必须有并发上限（当前为串行，等效上限 1），保持控制面请求可用。搜索不改变普通列表的分页与“禁止一次性拉全量”规则。

## P1-09 连接配置导入 / 导出（2026-10）

- 配置菜单提供连接导入/导出。默认导出脱敏配置；含凭据导出需明确勾选、二次确认与导出密码加密。
- 导入时同名连接默认跳过，可选择覆盖；格式/版本/密码错误不影响既有连接。支持读取 AWS CLI profile（`~/.aws/credentials` 与 `~/.aws/config`）并确认导入。

## P1-10 批量下载 ZIP（2026-10）

- 已选文件或文件夹可下载为 ZIP；文件夹保留其相对目录结构，多选文件保留完整 Key 路径以避免同名冲突，目录占位对象不进入 ZIP。
- ZIP 任务逐对象流式下载到短生命周期临时工作文件后立即写入 ZIP，不将整个对象或整个 ZIP 读入内存；可取消、显示进度，取消后删除未完成 ZIP。

## P1-21 桶列表过滤（2026-10）

- 桶列表顶部提供本地子串过滤输入框，仅过滤当前已加载的桶名，不额外请求服务端；不区分大小写。无匹配时显示占位提示，清空输入立即恢复完整桶列表。

## P1-22 大桶列表性能（2026-10）

- 对象表采用虚拟滚动，只渲染可视行及缓冲区。全选、排序与滚动加载仍以全部已加载条目为作用范围；不改变既有按页加载、禁止一次性拉取全桶的约束。
- 设计目标为百万对象桶可持续分页浏览；空目录、加载中与错误展示必须保持可用。

## P1-17 只读 / 防误删模式（2026-10）

- 连接编辑中可持久化开启只读模式。只读连接在界面显示锁定标识，并隐藏上传、删除、复制、移动、新建文件夹等写入口；下载、预览、复制 Key 保持可用。
- 后端必须拒绝写命令，不能仅依赖前端禁用。

## P1-11 仅上传新增 / 变更与空文件夹（2026-10）

- 上传确认框可选仅上传新增/变更；按远端同 key 大小比较，大小相同跳过并显示数量。目录内空文件夹写入零字节占位对象，确认框和任务中心一致展示数量。

## P1-12 完整性校验（2026-10）

- 下载完成自动校验单部件对象 ETag/MD5；不一致时明确报错并保留文件现场。分片复合 ETag 不做错误的整体 MD5 比对，明确跳过。

## P1-13 多窗口（2026-10）

- 工具栏提供“新窗口”，打开独立浏览窗口；所有窗口共享 Rust App 状态与任务注册表，因此任务中心显示同一组传输任务。每个窗口独立维护当前桶/前缀等前端浏览状态。
- 窗口关闭仍沿用进行中任务退出保护；关闭一个窗口不会取消全局任务。

## P1-14 命令面板与快捷键（2026-10）

- 提供 `Ctrl/Cmd+K` 命令面板，支持按名称过滤刷新、上传、搜索、新窗口、返回桶列表等命令。快捷键包含 `Ctrl/Cmd+R` 刷新、`Ctrl/Cmd+U` 上传、`Ctrl/Cmd+F` 搜索，并在面板内列出。
- 只读模式下上传快捷键保持禁用，快捷键与浏览器默认刷新/搜索行为冲突时优先应用内操作。

## P1-15 系统托盘与通知（2026-10）

- 系统托盘提供显示主窗口和退出菜单；退出走主窗口关闭流程，仍遵守进行中任务退出保护。传输在窗口隐藏或最小化后继续。
- 配置菜单可开关任务完成/失败通知，默认开启；通知权限不可用时不影响任务本身。

## 分发与平台

- 目标平台：**Windows、Linux、macOS 三端**（Windows NSIS、Linux AppImage + deb、macOS dmg，覆盖 Intel 与 Apple Silicon）。
- 构建注意：Windows / Linux 包可在 Linux CI 构建；**macOS 包必须在 macOS 上构建**（Tauri 不支持 macOS 交叉编译）。
