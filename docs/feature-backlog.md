## 实施约定（每项通用）

- 业务行为落地前先更新 `.agents/` 对应规格（`requirements.md` / `s3-operations.md` / `connection-config.md`）。
- 业务逻辑写进 `easys3-core`（无 GUI 依赖、可测）；`src-tauri` 仅做命令编排与任务生命周期。
- 每个功能完成时：`cargo fmt` + `cargo clippy -p easys3-core --all-targets -- -D warnings` + `cargo clippy -p easys3 --all-targets -- -D warnings` + `cargo test -p easys3-core` + `pnpm build` 全绿。
- 错误消息与日志不得出现 `secret_key`；新增耗时操作必须可取消并接入任务中心。

## P0 — 文件管理器基线

### [x] P0-01 桶内重命名 / 移动 / 复制（M，3–5 人日）

- **规格澄清**：现有红线"跨连接复制 / 同步 / 移动"仅指跨连接；桶内（含同连接跨桶）复制 / 移动 / 重命名不在红线内，已在 `s3-operations.md` §6 新增边界小节。
- **验收标准**
  - [x] 单对象重命名：服务端 `copy_object` + `delete_object`，改名后旧 key 消失、新 key 内容与元数据一致（服务端复制保留元数据）。
  - [x] 多选移动 / 复制到指定前缀：目标前缀由对话框选择（缺省当前前缀）；同名对象按统一冲突策略（覆盖 / 跳过；"取消"由对话框取消按钮承担）。
  - [x] 文件夹（前缀）重命名 / 移动：递归覆盖所有层级，0 字节目录占位对象一并处理（`collect_prefix_objects(true)`），目录重命名 = 修改目标前缀末段。
  - [x] 中文 / 空格 / Unicode key 全程原样支持（CopySource 编码单测 `copy_source_keeps_path_and_encodes_unicode`）。
  - [x] 作为 Copy 类型任务进入任务中心，可取消、失败可"精确命中重试"（重试槽保存原始列表项 + 目标前缀 + 冲突策略）。
  - [x] 同桶复制使用服务端 `copy_object`，不做整对象下载中转。
  - [x] 大对象（> 5GB）：`HeadObject` 前置检查，明确提示不支持分片复制（不静默失败，且不参与自动重试）。

### [x] P0-02 新建文件夹（S，≤2 人日）

- **验收标准**
  - [x] 工具栏提供"新建文件夹"，输入名称为当前前缀下创建 `前缀/名称/` 的 0 字节占位对象。
  - [x] 名称校验：非空、不含 `/`、不与现有条目重名（重名给出提示）。
  - [x] 创建后列表刷新可见该文件夹，进入后为空目录；落地行为与新规格一致。

### [x] P0-03 对象详情面板（只读元数据 / HTTP 头）（M，3–5 人日）

- **验收标准**
  - [x] 选中对象可打开详情：显示大小、最后修改、ETag、存储类别、Content-Type、`x-amz-meta-*`。
  - [x] 数据来自 `head_object`（控制面客户端，30s 超时）。
  - [x] 未授权读取元数据时给出分类错误（权限不足），不崩溃。
  - [x] 详情面板不触发对象体下载。

### [x] P0-04 存储类别显示与上传选择（M，3–5 人日）

- **验收标准**
  - [x] 对象列表新增"存储类别"列（`ListObjectsV2` 返回的 `StorageClass`，STANDARD 缺省显示 STANDARD）。
  - [x] 上传确认框可选目标存储类别，默认 STANDARD。
  - [x] 分片上传时存储类别透传到 `create_multipart_upload`。
  - [x] 存储类别列可排序 / 可隐藏（偏好持久化）。

### [x] P0-05 失败自动重试（瞬时错误）（M，3–5 人日）

- **验收标准**
  - [x] 仅对瞬时错误（连接失败 / 超时 / 5xx / SlowDown）自动退避重试，默认 3 次、可设置 0–10（`is_retryable` 有分类单测；本地 IO / 取消 / 配置错误也不重试）。
  - [x] 403 / 404 / 认证类错误不自动重试，直接计入失败。
  - [x] 重试过程在任务中心可见（当前文件 / 累计重试次数，指数退避 300ms 起）。
  - [x] 手动"重试失败项"语义不变，且与自动重试叠加不重复执行已成功对象。

### [x] P0-06 带宽限速（M，3–5 人日）

- [x] 验收标准
  - [x] 设置页可设全局上传 / 下载限速（KB/s，0 = 不限速）。
  - [x] 限速对单对象与多文件任务均生效（跨任务共享令牌桶；容量封顶 100ms 配额 + 欠账偿还模型，实测速度不超过设定值约 ±10%，refill 数学有单元测试；端到端实测需真实 S3 环境）。
  - [x] 速率变更对进行中任务即时生效（Throttle 速率热调整，保存设置即改）。
  - [x] 不限速时 acquire 立即返回，吞吐不低于改造前水平。

### [x] P0-07 传输参数可配置（并发 / 分片）（S，≤2 人日）

- [x] 验收标准
  - [x] 设置页可配：文件间并发数（默认 2，1–8）、multipart 分片大小（默认 8MB，范围 5–64MB）、最大并发任务数（默认 3，超出排队）。
  - [x] 参数持久化（应用配置目录 settings.json，缺失/损坏回落默认），重启后保留。
  - [x] 分片大小改动后新任务按新值分片（含 ≥5MB 下限兜底单测）；进行中任务不受影响。

### [x] P0-08 凭据安全升级（Keychain / 加密）（M，3–5 人日）

- [ ] 验收标准
  - [x] `secret_key` 优先存入 OS Keychain（Windows Credential Manager / macOS Keychain / Linux Secret Service），Keychain 不可用时 AES-GCM 加密落盘。
  - [x] `connections.json` 中不再出现明文 `secret_key`；前端读取连接状态不含密钥。
  - [x] 已有明文配置首次启动自动迁移，迁移后连接配置与密钥可继续使用。
  - [x] 密钥 / 口令不出现在日志、错误、前端事件中；编辑留空表示保留原密钥。
  - [x] 已同步更新 `connection-config.md` 的"存储与凭据安全"章节，并有 AES-GCM 兜底单元测试。

### [x] P0-09 预览扩展（PDF / 音视频 / 代码 / Markdown）（L，6–12 人日）

- [x] 验收标准
  - [x] 新增 PDF、常见音视频（mp4 / webm / mp3，另支持 wav / ogg / flac / m4a）预览，仍受大小上限约束（上限可配：设置页"预览大小上限"，默认 20MB，1–100MB，`HeadObject` 前置拒绝超限请求）。
  - [x] JSON / 常见代码文件按纯文本高亮渲染（字符串 / 注释 / 数字 / 关键词分词着色）；Markdown 渲染为只读结构化视图（标题 / 列表 / 引用 / 代码块 + 行内粗斜体）。全部为文本节点渲染，禁用 `v-html`，HTML 一律不渲染（防 XSS）。
  - [x] SVG 继续不预览；二进制 / 超限仍提示"请下载后查看"。
  - [x] PDF / 音视频以 data URL 内嵌展示，不经临时文件中转（无临时文件需删除；超长文本截断至 5000 行并提示下载查看）。
  - [x] 已更新 `s3-operations.md` §5 的类型与上限清单。

### [x] P0-10 下载后打开（M，3–5 人日）

- **范围调整**：删除“拖拽到系统文件管理器”子项（Tauri v2 无官方跨平台拖出方案，仅 macOS 有社区插件，Windows / Linux 目标平台不可行），验收范围收敛为“下载后打开”。
- [x] 验收标准
  - [x] 对象行提供"打开"：下载到系统临时目录 `easys3-open` 后用默认程序打开（`tauri-plugin-opener`）。
  - [x] 临时文件在应用退出时清理（`RunEvent::Exit` 删除临时目录）。
  - [x] 大文件打开给出进度反馈、不阻塞界面（下载经任务中心，可取消 / 可重试）。

### [x] P0-11 深色模式（M，3–5 人日）

- [ ] 验收标准
  - [x] 跟随系统深浅色，且可手动切换（浅 / 深 / 跟随），选择持久化。
  - [x] 页面、弹窗、任务中心、Toast、表格均使用主题变量，深色下保持可读。
  - [x] 切换无需重启。

### [x] P0-12 服务端碎片管理（M，3–5 人日，2026-10-09 增补）

- **背景**：easyS3 仅保证自己取消 / 失败时 `abort_multipart_upload`；其他工具或进程崩溃残留的服务端碎片用户不可见，持续占用存储。COSBrowser / ossbrowser / OBS Browser+ / CS Browser 均标配碎片管理。
- [x] 验收标准
  - [x] 工具入口"碎片管理"可列出该桶未完成的 multipart 上传（`ListMultipartUploads` 分页，含 key、发起时间、StorageClass）。
  - [x] 支持查看单个上传的分片明细（`ListParts` 分页），并可勾选单个 / 批量 `AbortMultipartUpload` 清理。
  - [x] 清理为高危操作，需二次确认；清理后逐项刷新（成功移除、失败保留），失败项可再次勾选重试。
  - [x] 权限不足 / 服务不支持该 API 时按错误分类给出中文提示（部分私有实现可能不支持）。
  - [x] 已在 `s3-operations.md` §7 落地小节（新能力，非红线解除）。

### [x] P0-13 记住下载目录 / 默认下载目录（S，≤2 人日，2026-10-09 增补）

- **背景**：当前每次下载都强制弹出目录选择框（`App.vue` 的 `requestDownload`），高频操作摩擦明显。
- [ ] 验收标准
  - [x] 「记住上次下载目录」默认开启；可设置、清除和更换默认下载目录，偏好本地持久化。
  - [x] 下载冲突对话框显示目标目录并提供「更换目录」入口（保留手动选择能力）。
  - [x] 未保存目录（或用户关闭记忆）时回退到目录选择框；任务启动阶段仍会由本地写入失败反馈不存在目录等异常。

## P1 — 效率与协作增强

### [ ] P1-01 断点续传 + 传输队列持久化（XL，>12 人日，⛔ 红线重评）

- **规格影响**：解除 `requirements.md` 红线"断点续传（上传下载均不做）"与"传输任务持久化（应用重启后任务不恢复）"。
- **验收标准**
  - [ ] 上传续传：中断后重开应用，可从已完成分片继续（`UploadId` 与已完成分片持久化）。
  - [ ] 下载续传：中断后可从断点用 HTTP Range 继续，最终文件与一次性下载一致（校验通过）。
  - [ ] 未完成任务重启后出现在任务中心并可一键恢复；超过保留期的残留 `UploadId` 提供清理入口。
  - [ ] 取消 / 放弃的任务正确 `abort_multipart_upload`，不留残片。
  - [ ] 续传对用户透明，不暴露 multipart / UploadId 等协议术语。

### [ ] P1-02 预签名 URL（下载 / 上传）（M，3–5 人日，⛔）

- [ ] 验收标准
  - [ ] 对象右键 / 操作区可生成下载用预签名 GET URL，可设过期时间（如 5 分钟 / 1 小时 / 自定义）。
  - [ ] 支持为前缀生成上传用 PUT URL（可选，供外部回传）。
  - [ ] **批量生成**（2026-10-09 增补）：多选对象 / 整前缀一次生成，统一有效期，支持导出 URL 清单文件——社区高频痛点（Reddit 有「8 万文件批量临时读权限无处可做」案例），竞品普遍缺失或收费。
  - [ ] URL 可一键复制，走 `plugin-clipboard-manager`；不在日志中输出完整签名。
  - [ ] 桶不支持 / 权限不足时给出分类提示。
  - [ ] 解除 `requirements.md` 红线"预签名 URL 分享"。

### [ ] P1-03 版本查看与单对象恢复（L，6–12 人日，⛔）

- [ ] 验收标准
  - [ ] 对象详情提供"版本"列表（`ListObjectVersions`），显示版本 id、大小、时间、是否删除标记。
  - [ ] 可选择某个历史版本恢复为当前版本（复制该版本为当前 key）。
  - [ ] 桶未开启版本控制时给出明确提示（不报未知错误）。
  - [ ] 不做全桶 Time Travel；解除"版本控制（列出 / 恢复历史版本）"红线。

### [ ] P1-04 对象标签查看 / 编辑 + 只读 ACL（L，6–12 人日，⛔ 部分）

- [ ] 验收标准
  - [ ] 对象标签（`GetObjectTagging` / `PutObjectTagging`）可查看、增删改并保存。
  - [ ] ACL 仅只读展示（`GetObjectAcl`），不提供修改（保留 ACL 管理红线）。
  - [ ] 权限不足时分类提示。

### [ ] P1-05 桶创建 / 删除 + 版本控制开关（M，3–5 人日，⛔）

- [ ] 验收标准
  - [ ] 可创建桶（桶名规范校验、region / 存储类别可选）。
  - [ ] 可删除桶，删除前二次确认并要求桶内为空（或明确提示）。
  - [ ] 可查看 / 切换桶版本控制状态（Enabled / Suspended）。
  - [ ] 限定单桶连接下不提供桶创建 / 删除入口。
  - [ ] 解除"桶的创建 / 删除"红线。

### [ ] P1-06 跨桶复制 / 移动（M，3–5 人日，⛔，依赖 P0-01）

- [ ] 验收标准
  - [ ] 同一连接下可将对象 / 前缀复制或移动到另一个桶。
  - [ ] 跨 region 时行为明确（服务端复制失败给出提示，或走下载中转，二选一并说明）。
  - [ ] 进入任务中心，可取消 / 重试。
